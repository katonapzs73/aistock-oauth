Privacy policy – AI Stock NAS

Last updated: 6 November 2026

Who uses the app

AI Stock NAS is a private program used only by its owner on the owner's own home server. There are no other users.

Google user data accessed

The app requests only the https://www.googleapis.com/auth/drive.file scope. With it the app can create one backup folder and upload, list, download and delete only the files it created there. It cannot read any other file in the user's Google Drive.

How the data is used

The uploaded files are backups of the owner's own database. They are encrypted on the owner's server before upload, so Google stores only unreadable data. The files are used only to restore the owner's own system.

Sharing and storage

No data is sold, shared with or transferred to any third party. Access credentials are stored only on the owner's own server. No analytics, advertising or tracking is used.

Deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the backup folder in Google Drive.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
